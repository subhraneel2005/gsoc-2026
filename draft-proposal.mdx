# About me
As a student I love to use FOSS software, and was always curious to know what it takes to build them. When i first discovered Github and saw engineers contributing their code on a single shared codebase, it amazed me and made me want to dig deeper.

The first project I contributed to was [Innovacion](https://github.com/benedicti0n/INNOVACION2025) our University's event website. I was genuinely happy when my first code got merged into the project, and through that project I also took my first steps into cloud deployment.

From there I kept building. Built hands on [projects](https://github.com/subhraneel2005), wrote short documentation and archtitecture notes for them and hosted everything on github. Last summer I did a 6-month remote internship as a fullstack intern at an ai powered jobs listing company. I contributed in building their [chrome extension](https://chromewebstore.google.com/detail/pnnponmefnlhnjjlkakmfniadlplhkll?utm_source=item-share-cb), handled large volumes of client-side data, and built their AI mock interview assistant from scratch.

# My journey in Sugarlabs till now
This January I came across SugarLabs. I explored the projects, found Music Blocks, and got genuinely excited by it. Although I have very less knowledge about musical instruments, still it was so easy to wander around. 

I started small: reading the codebase, joining the Matrix channel, introducing myself, picking up issues. Raised PRs, did several reviews, and a few raised issues later, I feel confident I understand the project well enough to contribute something meaningful this summer.
